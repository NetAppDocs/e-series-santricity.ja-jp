= SANtricity System Manager で SNMPv3 トラップのユーザーを削除する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SNMPv3トラップのユーザを削除できます。

.手順
. 左側のパネルから、メニュー：Alerts［SNMP alerts］を選択します。
+
トラップの送信先とユーザー名は、SNMPアラートページに表示されます。

. [ユーザーの設定]を選択します。
+
[Configure SNMPv3 Users]ダイアログボックスが開きます。

. 削除するユーザー名を選択し、*削除*をクリックします。
. 操作を確定し、*削除*をクリックします。


.結果
ユーザー名とそのユーザー名に関連付けられたトラップ送信先は、SNMPアラートページから削除されます。
