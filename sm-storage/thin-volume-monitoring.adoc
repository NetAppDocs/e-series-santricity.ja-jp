= SANtricityソフトウェアのシンボリューム監視について学ぶ
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
シンボリュームのスペースを監視して適切なアラートを生成し、容量不足が発生するのを回避できます。

シンプロビジョニング環境では、基盤となる物理ストレージ容量よりも多くの論理領域を割り当てることができます。メニュー：Storage［Thin volume monitoring］を選択すると、割り当てられた最大容量制限に達する前に、シンボリュームがどれだけ増加したかを監視できます。

Thin Monitoringビューを使用して、次の操作を実行できます。

* シンボリュームで自動的に拡張可能な割り当て容量を制限する制限を定義します。
* シンボリュームが割り当てられた最大容量制限に近づいたときに、ウィンドウの右上隅にあるベルのアイコンからアクセスできる通知領域にアラート（警告しきい値超過）が送信されるパーセンテージポイントを設定します。


シンボリュームの容量を拡張するには、レポート容量を拡張してください。

[NOTE]
====
System Managerには、シンボリュームを作成するオプションはありません。シンボリュームを作成する場合は、コマンドラインインターフェイス（CLI）を使用します。

====
[NOTE]
====
EF80、EF50、EF600/EF600C、またはEF300/EF300Cストレージシステムでは、シンボリュームは利用できません。
