= SANtricity System Managerで表形式のパフォーマンスデータを表示および保存します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
パフォーマンスグラフのデータを表形式で表示および保存することができます。これにより、表示するデータをフィルタできます。

.手順
. パフォーマンス ページから、*テーブル ビューへ移動* をクリックします。
+
選択したオブジェクトのすべてのパフォーマンスデータを示すテーブルが表示されます。

. 表示するデータを選択するには、*オブジェクトの種類* と *時間範囲* を使用し、その後 *更新* をクリックしてください。
. [列の表示/非表示*]ボタンをクリックして、テーブルに含める列を選択します。
+
各チェックボックスをクリックして、項目を選択または選択解除できます。

. 表メニューから*CSVにエクスポート*を選択すると、表形式のビューがカンマ区切り値（CSV）ファイルに保存されます。
+
ブラウザの設定に応じて、ファイルが保存されるか、ファイルの名前と場所を選択するように求められます。

+
デフォルトのファイル名形式は `performanceStatistics-<storage array name>-yyyy-mm-dd_hh-mm-ss.csv`で、ストレージアレイ名とファイルがエクスポートされた日時が含まれます。
